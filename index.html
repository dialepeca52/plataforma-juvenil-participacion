Plataforma Juvenil para amar a la comunidad de forma monogamica jaja

Este proyecto es una práctica académica para apreder sobre participación juvenil, transparencia y control ciudadano.

Propósito del proyecto

Esta plataforma se construirá progresivamente como ejercicio pedagógico para comprender cómo la tecnología puede apoyar procesos comunitarios de participación y organización.

advertencia pedagógica

Este proyecto no corresponde a una elección rela, no recolecta datos personales reales y no debe utilizarse para hacer acusaciones.
